# ASCII図解エディタ (Obsidianプラグイン)

AIに図解で指示を出すためのASCIIアート(罫線図)を、方眼紙のようなグリッドエディタで作成できるObsidianプラグインです。

コピペしても位置関係が崩れないよう、**1マス = 全角1文字**(空白マスは全角スペース U+3000)に統一して出力します。

## インストール

`manifest.json` / `main.js` / `styles.css` の3ファイルを Vault の
`.obsidian/plugins/ascii-diagram-editor/` にコピーし、
設定 → コミュニティプラグイン で「ASCII図解エディタ」を有効化します。

開き方: 左のリボンのグリッドアイコン、またはコマンドパレット「ASCII図解エディタ: エディタを開く」。

## 使い方

### ツール(ツールバー左から)

| ツール | 操作 |
|---|---|
| 選択 | ドラッグで範囲選択。選択範囲をドラッグ or **矢印キー**で移動(Ctrl+ドラッグで複製)。Ctrl+C / X / V、Delete、右クリックメニュー対応 |
| ペン | パレットで選んだ文字をクリック・ドラッグで配置。右クリックで消去、Alt+クリックでセルの文字を取得 |
| 消しゴム | クリック・ドラッグで消去 |
| 直線 | ドラッグで直線・L字線(Shiftで縦優先)。既存の罫線と交差すると `├` `┼` などに自動接続 |
| 四角 | ドラッグで枠を描画。線種は「細 / 太 / 二重」を選択可能 |
| テキスト | セルをクリックして文字入力(日本語IME対応)。Enterで改行、Escで終了 |

### パレット

罫線(細・太・二重)/ 矢印 / 図形(□◆●…)/ カッコ(「」【】［］…)/ 記号 が常時表示されています。

- **クリック** → ペンツールでその文字を配置
- **グリッドへドラッグ&ドロップ** → その位置に直接配置
- **スタンプ**(`［　］`、箱、矢印線など) → クリックで連続配置モード、ドラッグ&ドロップでも配置可能

### コピペで配置が崩れない仕組み

1. 全マスが全角1文字(半角入力は自動で全角へ変換、空白は全角スペース)なので、どの行も「文字数 = マス目の位置」になり、論理的な位置関係が必ず保たれます。
2. 「全体コピー」はデフォルトでコードブロック(``` )で囲むため、AIチャットやMarkdownに貼っても等幅で表示されます。
3. AIは文字の列位置で図を解釈するため、この形式ならエディタ上のイメージ通りに伝わります。

### 入出力

- **全体コピー**: 図全体をクリップボードへ
- **ノートへ挿入**: 最後に開いていたノートのカーソル位置に挿入
- **読み込み**: クリップボードのテキスト(過去に作った図など)をグリッドへ読み込み
- グリッドの内容は自動保存され、Obsidianを再起動しても復元されます

### ショートカット

| キー | 動作 |
|---|---|
| Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y | 元に戻す / やり直す |
| Ctrl+C / X / V | 選択範囲のコピー / 切り取り / 貼り付け(貼り付けはホバーでプレビュー、クリックで確定) |
| Ctrl+A | 全選択 |
| 矢印キー | 選択範囲を1マス移動 |
| Delete / Backspace | 選択範囲を削除 |
| Esc | 選択・貼り付け・スタンプの解除 |

## 設定

- 半角文字を全角に自動変換(既定: ON)
- コピー時にコードブロックで囲む(既定: ON)
- 行末の空白を削除してコピー(既定: ON)
- 新規グリッドの幅・高さ

## 開発メモ

ビルド不要のプレーンJavaScript構成です。ファイルを編集したら Vault のプラグインフォルダへコピーし、
`obsidian plugin:reload id=ascii-diagram-editor` でリロードできます。
